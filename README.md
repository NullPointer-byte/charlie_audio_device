# Charlie Audio Device

**Bluetooth-аудиоколонка на ESP32 с OLED-дисплеем и синхронизацией времени по NTP**

> Автор: Kirill Borisenko · Made in Russia 🇷🇺

---

## 📖 Описание

**Charlie Audio Device** — это DIY-проект Bluetooth-колонки на базе ESP32. Устройство принимает аудиопоток по Bluetooth A2DP со смартфона, декодирует его и передаёт на цифровой усилитель **MAX98357A** через шину **I2S**. На OLED-дисплее отображается название трека (AVRCP-метаданные), текущая дата и время, синхронизированные через интернет по протоколу NTP.

Дополнительно в Serial-порт выводится диагностика: количество принятых аудиопакетов, объём PCM-данных, состояние подключения и метаданные трека (исполнитель, альбом).

---

## ✨ Возможности

- 🎵 Приём аудио по **Bluetooth A2DP** (SBC-кодек)
- 🔊 Вывод звука через **I2S** на усилитель MAX98357A
- 📺 OLED-дисплей **SSD1306 128×64** (I2C)
- 🕐 Синхронизация времени по **NTP** (часовой пояс — GMT+3)
- 📝 Отображение **AVRCP-метаданных** (название трека)
- 📊 Диагностика аудиопотока в Serial-порту
- 🔌 Управление питанием усилителя через пин `SD` (shutdown)

## 🔌 Распиновка

### Усилитель MAX98357A (I2S)

| Сигнал | Пин ESP32 | GPIO |
|--------|-----------|------|
| **SD** (Shutdown / Enable) | `AMP_SD` | **33** |
| **BCLK** (Bit Clock) | `I2S_BCLK` | **27** |
| **LRC** (Word Select / LRCLK) | `I2S_LRC` | **26** |
| **DIN** (Data In) | `I2S_DIN` | **25** |
| **GND** | — | GND |
| **VIN** | — | 5V (или 3.3V) |

> ⚠️ `AMP_SD` удерживается в состоянии `HIGH` — усилитель включён. Подача `LOW` отключает усилитель.

### OLED-дисплей SSD1306 (I2C)

| Сигнал | Пин ESP32 | GPIO |
|--------|-----------|------|
| **SDA** | `MY_SDA` | **19** |
| **SCL** | `MY_SCL` | **18** |
| **VCC** | — | 3.3V |
| **GND** | — | GND |

> Адрес дисплея по умолчанию — `0x3C`.

### Сводная таблица GPIO

| GPIO | Назначение |
|------|------------|
| **18** | I2C SCL (OLED) |
| **19** | I2C SDA (OLED) |
| **25** | I2S DIN (данные → усилитель) |
| **26** | I2S LRC (word select) |
| **27** | I2S BCLK (тактовый сигнал) |
| **33** | AMP_SD (enable усилителя) |

## 🧩 Используемые библиотеки

Arduino IDE: https://github.com/arduino/arduino-ide
Установите через **Arduino Library Manager**:

| Библиотека | Назначение |
|------------|------------|
| `AudioTools` (pschatzmann) | Абстракция I2S-потока |
| `BluetoothA2DPSink` (pschatzmann) (https://github.com/pschatzmann/ESP32-A2DP) | Bluetooth A2DP-приёмник |
| `Adafruit GFX Library` | Графическое ядро для дисплея |
| `Adafruit SSD1306` | Драйвер OLED SSD1306 |

Встроенные в ESP32 (Core):
- `WiFi.h` — подключение к сети
- `Wire.h` — I2C
- `time.h` — NTP и работа со временем

## ⚙️ Настройка

Перед прошивкой отредактируйте параметры в начале скетча:

### Wi-Fi

```cpp
const char* wifi_ssid     = "florestdev";
const char* wifi_password = "florestdev-victoria123";
```

### Часовой пояс (NTP)

```cpp
const long gmtOffset_sec     = 10800; // GMT+3 (Москва)
const int  daylightOffset_sec = 0;
```

- `gmtOffset_sec` — смещение от UTC в секундах
- `daylightOffset_sec` — летнее время (для РФ — `0`)

### Параметры I2S

```cpp
cfg.sample_rate     = 44100;
cfg.bits_per_sample = 16;
cfg.channels        = 2;
cfg.i2s_format      = I2S_STD_FORMAT;
```

### Имя Bluetooth-устройства

```cpp
a2dp_sink.start("Charlie (florestdev)");
```

Именно это имя вы увидите в списке Bluetooth-устройств на телефоне.

## 🚀 Прошивка и запуск

1. Установите **Arduino IDE** и ядро **ESP32** (Boards Manager).
2. Установите перечисленные библиотеки.
3. Подключите ESP32, выберите плату (например, `ESP32 Dev Module`) и COM-порт.
4. Откройте `bluetooth_audio.ino` и прошейте.
5. Откройте **Serial Monitor** на скорости **115200 бод** — там будет лог инициализации.
6. На смартфоне найдите устройство **`Charlie (florestdev)`** и подключитесь.

## 📟 Serial-диагностика

Каждую секунду в Serial-порт выводится отчёт:

```
------ AUDIO DIAGNOSTICS ------
Total packets: 4821
Total bytes: 771360
[OK] Bluetooth audio data received!
[OK] PCM stream active
-------------------------------
```

Если пакеты не приходят — вы увидите `[WARN] No new audio packets!`. Это помогает быстро локализовать проблему (нет подключения, неверные пины I2S, усилитель выключен).

## 🛠️ Возможные проблемы

| Симптом | Причина / Решение |
|---------|-------------------|
| Нет звука | Проверьте `AMP_SD = HIGH`, питание усилителя, пины I2S |
| Тишина, но пакеты идут | Неверный `sample_rate` или перепутаны BCLK/LRC/DIN |
| Дисплей не светится | Проверьте адрес I2C (`0x3C`), пины SDA/SCL, питание |
| Время `--.--.----` | Нет подключения к Wi-Fi / NTP-сервер недоступен |
| Не видно в Bluetooth | Прошейте ещё раз, убедитесь, что `a2dp_sink.start()` вызван |
| Треск / прерывания | Проблемы питания, плохой контакт, помехи Wi-Fi |
